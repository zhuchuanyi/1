# 主动ETF · 点击展开与选股演示 V6

1920×1080、16:9横版、30fps，约1分57秒。保留石墨黑空间、烟灰玻璃、中文男声与字幕。

## 本次修改

1. 开场“多一种选择”外围增加一束银白光线：明确亮头、分级短尾、局部软光，按真实路径周长运行一整圈后收束。没有粒子或整屏泛光。
2. 说到“主动管理”时，鼠标点击左侧玻璃按钮，遮罩展开基金经理选股页面。经理面前的屏幕绘制价格走势，依次选入标的A、C。
3. 说到“ETF”时，鼠标点击顶部ETF入口，展开持仓和交易软件页面：分布环图、权重列表、数字报价与走势。所有标的、报价、权重和曲线为机制示意。
4. 总结口播时回到原来的双按钮界面，呈现“基金经理选择策略”“争取跑赢基准”。

## 时长与声音

在主动管理讲解后加入3秒无声间隔，让选股动画可读。原始语音字节未重写、未加速；后续镜头整体顺延3秒，原有内容与各镜持续时间保持。总长约116.84秒，小于两分钟。音乐延长并加入两次轻点击声。

## 工程

- `index.html`：可编辑SVG角色、界面、鼠标与GSAP时间轴。
- `DESIGN.md`：本版视觉与动作规范。
- `timing.json`、`subtitles.srt`：更新后的短句时点与字幕。
- `voice-emphasis.json`：51处语音强调目标与时间。
- `assets/`：字体、分镜配音、音乐、GSAP及动效库适配。

Node.js22+与FFmpeg环境运行`npm run dev`预览、`npm run check`检查、`npm run render`渲染。CLI锁定0.8.185。项目内包含全部渲染所需媒体。
