# 主动ETF · 石墨黑空间 V5

1920×1080、16:9横版、30fps，约1分54秒。保留中文男声、同步字幕与稀疏氛围音乐，更新为用户确认的深色极简视觉。

## 本版变化

- 全片暖白背景改为有层次的石墨黑/深空灰空间，非纯黑；烟灰透明玻璃主体，银灰只用于细边与反射，深红作极小重音。
- 开场删除玻璃列阵与左右分栏。两句居中上下排列：0.2秒先出现“主动ETF”，2.8秒再出现“多一种选择”。
- StarBorder适配只作用于第二句：3.3秒起细银灰短线走一圈，5.7秒前收束，无按钮底板、常驻边框、泛光或粒子。
- 第二句随对应讲解放大3%后复原，第一句不额外放大。其他镜头的51处语音强调、文件夹展开与分支细线保留。

## 工程

- `index.html`：可编辑HyperFrames主合成与SVG图解。
- `DESIGN.md`：本版材质、颜色、字体和动作规范。
- `voice-emphasis.json`：52处语音强调的目标与起止时间。
- `timing.json`：分镜与配音短句时间。
- `subtitles.srt`：独立字幕。
- `assets/`：分镜配音、音乐、字体、GSAP与动效库适配脚本。

所有依赖媒体在项目内。Node.js22+与FFmpeg环境中运行`npm run dev`预览、`npm run check`检查、`npm run render`渲染。CLI锁定0.8.185。

## 验证与内容口径

HyperFrames运行、布局、动作与文字对比度检查通过。逐项验证52处强调中点达到1.03、结束恢复1.00；开场第二句延迟出现，第一句保持原尺寸，StarBorder有限单圈且结束隐藏。最终MP4另行完整解码与关键帧核验。

配音短句时点来自既有音频，句内关键词时点按文字权重估算，可通过强调时间表微调。信息日期2026-10-22，发行日期2026-10-23；发行认购与上市交易分开表述，PCF不等于实时交易记录，主动管理不保证超额收益。
